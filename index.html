Наші послуги

Все для ідеального свята

01

Холодні фонтани

Ефектні фонтани з холодних іскор висотою 2 метри, час горіння 30 секунд. Безпечно, видовищно, незабутньо. Ідеальні для першого танцю, розрізання торту або урочистого виходу молодят.

02

Важкий дим

Низький туман для першого танцю «в хмарах» або ефект густого диму для фотозони. Безпечний для гостей та відмінно виглядає на фото.

03

Кольорові спалахи

Яскраві кольорові спалахи для акцентування ключових моментів вечора — виходу молодят, першого поцілунку, фінального танцю.

04

Бенгальські вогні

Романтичний живий коридор з бенгальських вогнів для виходу молодят. Ваші гості стають частиною шоу.
